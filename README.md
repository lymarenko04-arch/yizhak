# Їжак — веб-приложение (пилот)

Приложение устанавливается на телефон как приложение (PWA): открыть ссылку → «Добавить на главный экран».

## Что уже работает

- **Покупатель:** вход по имени и телефону, город, льготная категория с согласием, лента наборов, фильтры (бесплатно, категории, халяль), настоящая карта OpenStreetMap, бронь с 4-значным кодом, маршрут в Google Maps, отмена, отзыв со звёздами.
- **Магазин:** регистрация (адрес сам находится на карте), новый набор с фото с камеры, скидка 30/50/70%, своя цена или «бесплатно льготникам», количество, вес, время выдачи. Выдача по коду: магазин не видит коды заранее, покупатель называет его сам.
- **Владелец (скрыто):** 5 быстрых нажатий на логотип; открывается только аккаунту с ролью `owner` (в тестовом режиме — по PIN). Спасённые кг, сэкономленные людям деньги, выданные наборы, оборот, разбивка по городам. Цель, до которой комиссия 0% и включить её нельзя.
- **Пилот без юрлица:** приложение не принимает деньги. Оплата в магазине наличными или картой магазина.

## Сервер (подключён)

Данные хранятся в Supabase и общие для всех телефонов. Адрес и публичный ключ — в `js/config.js`.
Если там стереть `SUPABASE_URL`, приложение вернётся в тестовый режим (данные только на одном устройстве).

- **Вход в пилоте:** без почты и SMS (анонимная сессия + имя и телефон в профиле). Если очистить браузер или сменить телефон, доступ к аккаунту теряется. Позже добавим привязку почты.
- **Владелец:** доступ по роли `owner` в базе, не по PIN. Как назначить — `supabase/admin.sql`.
- **Безопасность:** правила проверяет база (`supabase/schema.sql`): лимиты броней, коды видны только покупателю, роль и цену подделать нельзя.
- **Тестовые данные:** удалить командой из `supabase/admin.sql`.

## Запуск на компьютере

```powershell
python -m http.server 8766 --directory yizhak-app
```
Открыть http://localhost:8766

## Следующий шаг: постоянная ссылка

Выложить папку на бесплатный хостинг (Netlify, Cloudflare Pages или GitHub Pages) — появится ссылка с https, которую можно раздать магазинам.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | оболочка приложения |
| `css/app.css` | стили, светлая и тёмная тема, шрифт Nunito |
| `js/app.js` | экраны, навигация, действия |
| `js/store.js` | выбирает сервер или тестовый режим |
| `js/remote.js` | работа с сервером Supabase |
| `js/local.js` | тестовый режим на одном устройстве |
| `js/ui.js` | иконки, форматы, справочники |
| `js/config.js` | настройки, города, цель и комиссия |
| `sw.js`, `manifest.webmanifest`, `icons/` | установка на телефон и офлайн |
| `supabase/schema.sql` | база данных для сервера с защитой доступа (уже запущена) |
| `supabase/admin.sql` | команды владельца: удалить тест, назначить себя владельцем |
